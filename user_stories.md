# CineTrack - User Stories

1. **User Registration**
   As a new user, I want to create an account using my username, email, and password so that I can access personalized features of the CineTrack app.

2. **User Login**
   As a registered user, I want to log in securely with my email and password so that I can access my saved movies and preferences.

3. **Discover Trending Movies**
   As a movie enthusiast, I want to view a list of currently trending and popular movies on the Home screen so that I can stay up to date with the latest cinema trends.

4. **Search Movies via API**
   As a user looking for specific content, I want to search for movies using an external database (API) so that I can find detailed information about any film.

5. **View Movie Details**
   As a user, I want to view detailed information about a specific movie, including its synopsis, release date, and ratings, so that I can decide whether to watch it.

6. **Manage Favorites (Watchlist)**
   As a user, I want to add movies to my "Favorites" list so that I can keep track of the films I plan to watch later.

7. **Local Data Persistence**
   As a user, I want my Favorites list to be saved locally on my device so that my data remains available even after I close the app or go offline.

8. **Customizable Settings**
   As a user, I want to access a settings menu to toggle app preferences like theme modes (Dark/Light) or account details to customize my experience.

9. **Receive Notifications**
   As a user, I want to receive and configure notifications for new movie releases or reminders so that I never miss an important update.
